# ObsidianFlow

ObsidianFlow is a highly scalable, fault-tolerant system that enables real-time knowledge processing and auto-scaling architecture.

With ObsidianFlow, you get a lightweight tool that stays out of your way.

**What you get**

- ObsidianFlow is a highly scalable,
- fault-tolerant system that enables real-time
- knowledge processing and auto-scaling architecture

## Technology Stack

- typescript
- typescript framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/ObsidianFlow.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
